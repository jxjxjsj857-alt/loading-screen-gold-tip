A single loading-screen tip (110 characters) for stressed developers and AI coding agents, written for make.fun's "Loading Screen Gold: A Tip in 200 Characters" bounty.

> Tip: that spinner isn't loading anything. It's your agent stalling before it admits it rewrote the wrong file.

## Run it

```sh
python3 main.py
```

It writes the tip to `/output/entry.txt` (1–200 characters, UTF-8, one line).
